
# 📊 AWS Cloud-Based Data Analytics Pipeline (SQL + Python + Redshift)

This project simulates a complete AWS-native data analytics workflow using Athena, Python, SQL, and Redshift to transform raw e-commerce data into actionable insights.

## 🚀 Project Highlights

- Built an ELT data pipeline using AWS S3, Athena, and Python
- Transformed data using SQL scripts and Python Pandas
- Stored curated data in Amazon Redshift for dashboarding
- Used PostgreSQL for intermediate staging and aggregation
- Emphasized AWS-native tools and real-time analytical capabilities

---

## 🛠 Tech Stack

- **AWS S3**: Raw + processed data storage
- **AWS Athena**: Serverless querying for large files
- **AWS Glue Catalog**: Metadata management
- **Python**: Data wrangling and transformation
- **Amazon Redshift**: Data warehouse for reporting
- **PostgreSQL**: Staging & transformation
- **SQL**: Complex joins, aggregations, KPI modeling
